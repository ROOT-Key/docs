<Warning>
  **Page size and cursor.** `limit` is a whole number from 1 to 100 (default 10), and `order` is `asc` or `desc`; anything else gets a `400` [`invalid_pagination`](/api-reference/errors#invalid_pagination). A `cursor` must be the `pagination.nextCursor` of the previous page, unchanged. A cursor in the old form, an ISO date, gets a `400` [`invalid_cursor`](/api-reference/errors#invalid_cursor): start again from the first page.
</Warning>
