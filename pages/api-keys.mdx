## How to Create an API Key

<Note>
  A key belongs to the environment that is active when you create it. To create a **test key**, turn on test mode first (step 3), then create the key. A test key works on your organization's test data, against the same API as a live key. See [Test and Live Data](/pages/environments).
</Note>

<Steps>
  <Step title="Log in and open the Dashboard">
    Go to [app.rootkey.ai](https://app.rootkey.ai/sign-in?utm_source=api_docs&utm_medium=api_keys_page&utm_content=login) and sign in. You will land on the Dashboard. If you belong to more than one organization, select the one the key is for.

    <img style={{ borderRadius: "2px" }} src="/images/api-keys/01-dashboard.png" alt="ROOTKey Dashboard with the organization selected" />
  </Step>

  <Step title="Open Developer Tools">
    In the left sidebar, under **Connect**, click **Developer Tools**. If your organization has no keys yet, you will see the getting-started page with **Create your first API key**.

    <img style={{ borderRadius: "2px" }} src="/images/api-keys/02-developer-tools.png" alt="Developer Tools getting-started page" />
  </Step>

  <Step title="Choose the environment">
    Open the **API Keys** tab and click **Actions** in the top right corner. For a test key, click **Turn on test mode**. For a live key, leave test mode off.

    <img style={{ borderRadius: "2px" }} src="/images/api-keys/03-actions-menu.png" alt="Actions menu with Create API key and Turn on test mode" />

    While test mode is on, a yellow banner is shown at the top of the page.

    <img style={{ borderRadius: "2px" }} src="/images/api-keys/04-test-mode.png" alt="API Keys tab in test mode, with the test mode banner" />
  </Step>

  <Step title="Fill in the key details">
    Click **Actions** > **Create API key**. Enter a **Key Name**, an optional description, and choose an icon to help identify this key. Click **Generate Key** when ready.

    <img style={{ borderRadius: "2px" }} src="/images/api-keys/05-key-details.png" alt="Create your new API Key form" />
  </Step>

  <Step title="Copy and store your key">
    Your new API key is displayed once. Copy it, or download it, and store it in a secure location - it will not be shown again after you click **Done**.

    <img style={{ borderRadius: "2px" }} src="/images/api-keys/06-key-created.png" alt="API Key Created dialog, with the key value hidden" />
  </Step>

  <Step title="Confirm the key is active">
    The key appears in the API Keys list with an **Active** status and a request counter. Expand it to see its environment and permissions. You are ready to authenticate API calls.

    <img style={{ borderRadius: "2px" }} src="/images/api-keys/07-key-active.png" alt="API Keys list with the new key active" />
  </Step>
</Steps>

## Using Your API Key

Pass the key in the `x-api-key` header on every request:

```http
x-api-key: YOUR_API_KEY
```

→ See [Authentication](/api-reference/auth) for the full reference and error handling.

An AI agent or a script that should act as a person, with only that person's access, can use a [personal access token](/api-reference/auth#personal-access-tokens) instead of an API key.

## Best Practices

<AccordionGroup>
  <Accordion title="Never expose your key in client-side code" icon="file-shield">
    API keys grant full access to your workspace. Keep them server-side and use environment variables - never commit them to source control or include them in frontend bundles.
  </Accordion>
  <Accordion title="Use one key per integration" icon="key">
    Create a separate key for each application or environment. This makes it easy to rotate or revoke a single integration without affecting others.
  </Accordion>
  <Accordion title="Rotate keys periodically" icon="arrows-spin">
    Regenerate keys on a regular schedule and immediately on any suspected exposure. Old keys can be revoked from the Developer Tools panel without downtime if a replacement is in place.
  </Accordion>
  <Accordion title="Monitor usage" icon="magnifying-glass">
    The Developer Tools Overview tab shows request volume and error rates per key. Unusual spikes may indicate misuse or an integration issue.
  </Accordion>
</AccordionGroup>
